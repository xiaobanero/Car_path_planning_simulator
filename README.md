# 路径规划模拟（C++ / SDL2）

这是一个基于 `C++17 + SDL2 + SDL2_ttf` 的交互式路径规划仿真程序。  
你可以在网格画布上构建道路、放置起点/终点建筑、生成小车并观察其自动寻路、等待避让、到站回收，以及在监控窗口中对每台小车进行实时调度。

---

## 1. 项目结构

- `cpp/src/main.cpp`：主程序源码（图结构、路径规划、渲染、交互、监控）
- `cpp/CMakeLists.txt`：CMake 构建脚本
- `res_map/`：运行时自动创建，保存/读取地图二进制文件（`.bin`）

---

## 2. 环境要求

### 2.1 系统与工具

- Windows 10/11（代码包含 Win32 文件对话框调用）
- CMake >= 3.16
- 支持 C++17 的编译器（建议 MSVC 2022）
- 包管理器：`vcpkg`（推荐，用于安装 SDL 依赖）

### 2.2 第三方依赖

- `SDL2`
- `SDL2_ttf`

程序会尝试从以下系统字体加载中文（无需手动配置字体文件）：

- `C:/Windows/Fonts/msyh.ttc`
- `C:/Windows/Fonts/msyhbd.ttc`
- `C:/Windows/Fonts/simhei.ttf`
- `C:/Windows/Fonts/simsun.ttc`
- `C:/Windows/Fonts/msyh.ttf`

## 3. Windows 下从零配置并运行

以下步骤以 PowerShell 为例。

### 3.1 安装依赖（vcpkg）

如果你还没有安装 `vcpkg`：

```powershell
git clone https://github.com/microsoft/vcpkg.git
cd vcpkg
.\bootstrap-vcpkg.bat
.\vcpkg install sdl2 sdl2-ttf
```

### 3.2 配置工程

在项目根目录执行：

```powershell
cmake -S .\cpp -B .\cpp\build `
  -DCMAKE_TOOLCHAIN_FILE="C:/path/to/vcpkg/scripts/buildsystems/vcpkg.cmake"
```

> 将上面的 `C:/path/to/vcpkg` 替换为你本机实际路径。

### 3.3 编译

```powershell
cmake --build .\cpp\build --config Release
```

### 3.4 运行

```powershell
.\cpp\build\Release\path_planning_sim.exe
```

如果是单配置生成器（如 Ninja），可执行文件通常在：

```text
cpp/build/path_planning_sim.exe
```

## 4. 快速上手（推荐流程）

1. 点击 `无模式`，在主画布用鼠标左键拖动绘制道路节点
2. 点击 `设置起点`，选择建筑预设后在画布放置起点
3. 点击 `设置终点`，放置终点建筑
4. 在起点上右键生成小车（自动分配目标终点并寻路）
5. 通过右侧控制面板调整全局暂停/速度
6. 在“小车控制与监控”窗口中对单车改终点、调速度、批量从起点发车

## 5. 功能总览

### 5.1 地图与路径构建

- 网格画布大小固定（道路节点可在网格上创建）
- 支持鼠标拖动连续画路，自动与上下左右邻格连通
- 起点/终点可用建筑预设放置（共 8 种形状）
- 建筑放置包含碰撞与越界检查，禁止重叠
- 支持删除单个路径点、起点、终点及其建筑覆盖区域

### 5.2 寻路与车辆行为

- 使用 Dijkstra 最短路径算法规划路线
- 起点编号与终点编号一一对应（`S1 -> E1`，`S2 -> E2` ...）
- 若对应终点尚未创建，小车进入“等待终点”状态；终点出现后自动出发
- 多车接近时触发避让等待（按 ID 优先级）
- 同一节点形成排队时，后车等待
- 到达终点后车辆自动移除
- 路径被删除导致不可达时，车辆会尝试重规划；失败后停止

### 5.3 主窗口控制面板

- 模式切换：`无模式` / `设置起点` / `设置终点`
- 全局控制：`重置所有`、`全局暂停/继续运行`
- 速度控制：`减速 -` / `加速 +` / 拖动时间流速滑条（0.25x ~ 4.0x）
- 地图持久化：`保存当前` / `打开之前`（二进制 `.bin`）
- 统计信息：路径点数、起点数、终点数、小车数、全局状态、时间流速

### 5.4 独立监控窗口（小车控制与监控）

- 查看每台小车：ID、坐标、速度、目标终点、状态
- 从当前选中起点批量发车（上一个起点 / 下一个起点 / 生成小车）
- 对单车操作：
  - 修改目标终点（输入终点编号）
  - 恢复默认速度
  - 速度 `-` / `+`
  - 切换到上一个/下一个终点

## 6. 操作方法（完整）

### 6.1 鼠标操作（主窗口）

- **左键**
  - 点击：在当前格创建路径节点
  - 拖动（无模式）：连续画路
  - 在“设置起点/终点”模式：放置对应建筑（若可放置）
- **右键**
  - 在起点上：立刻生成小车
  - 在非起点上：提示“只能在起点生成小车”
- **中键**
  - 优先删除鼠标命中的小车
  - 否则删除命中的起点/终点建筑
  - 再否则删除普通路径节点

### 6.2 键盘快捷键（主窗口）

- `S`：切换到设置起点模式
- `E`：切换到设置终点模式
- `R`：清空地图与车辆（等价重置）
- `Space`：全局暂停 / 继续
- `-` / 小键盘 `-`：减速
- `=` / `+` / 小键盘 `+`：加速

### 6.3 建筑预设选择

- 在设置起点或设置终点模式下，可选 1~8 号建筑预设
- 建筑预览为绿色表示可放置，红色表示不可放置

### 6.4 地图保存/加载

- 点击 `保存当前`：选择路径并保存为 `.bin`
- 点击 `打开之前`：选择 `.bin` 并恢复地图
- 存档目录默认在运行目录下的 `res_map/`

---

## 7. 状态说明

- `行驶`：按当前路径前进
- `等待`：避让或排队中，等待后继续
- `等终点`：尚无对应编号终点
- `停止`：路径失效且无法重规划
- `到达`：已到达终点，将被自动移除

---

## 8. 常见问题排查

- **启动报 `SDL_Init` / `TTF_Init` 失败**
  - 检查 SDL2/SDL2_ttf 是否正确安装并被 CMake 找到
  - 确认运行目录下 DLL 可被加载（vcpkg + CMake 一般会自动处理）
- **中文乱码或不显示**
  - 确认系统存在 README 中列出的中文字体
- **无法保存/打开地图**
  - 确认程序对当前目录有写权限
  - 检查 `res_map/` 是否可创建
- **小车不动**
  - 检查是否全局暂停
  - 检查起点与目标终点之间是否存在连通路径
